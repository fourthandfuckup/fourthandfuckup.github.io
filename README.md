# The Fourth & Fuckup Tribune

Static, mobile-friendly vintage newspaper website for GitHub Pages.

## Publish

Upload `index.html`, `style.css`, and `script.js` to the **root** of the `fourthandfuckup.github.io` repository's `main` branch. GitHub Pages should be set to `Deploy from a branch` > `main` > `/(root)`.

## Important before launch

- The inaugural article is deliberately a **preview**, not the full manuscript; replace it only after the real Sunday results and approved final story are ready.
- The Frank portrait is a placeholder until approved art is available.
- Instagram, Substack, and Google Forms links are not fabricated; add them after those accounts exist.
- Google Analytics is **not installed yet**. Set it up later with the owner's own GA4 measurement ID and appropriate privacy/consent arrangements. Never put account credentials or API secrets in this repository. Analytics reports live privately in the Google Analytics dashboard, not on this public site.
- Email tip-line works through a `mailto:` link; a hosted submission form is not yet connected.
- Google Fonts require internet connectivity.

## Editing

The site is one `index.html` shell, one `style.css` stylesheet, and one `script.js` file containing section templates. No build system required.
